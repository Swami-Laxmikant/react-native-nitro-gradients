# Using Without Reanimated

Currently this library requires [Reanimated (4.0+)](https://github.com/software-mansion/react-native-reanimated). If you need support without Reanimated, [open an issue on GitHub](https://github.com/Swami-Laxmikant/react-native-nitro-gradients/issues/new?title=Support%20usage%20without%20Reanimated&labels=enhancement).
